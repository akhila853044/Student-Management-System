
# Student Management System

## Project Overview
A simple Student Management System developed using Java.
This project helps manage student information efficiently.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner

## Features
- Add student details
- View student records
- Menu-driven interface
- Store student details during program execution

## Concepts Used
- Classes and Objects
- Constructors
- Methods
- ArrayList
- Loops and Switch Statements
